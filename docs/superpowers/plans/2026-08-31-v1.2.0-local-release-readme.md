> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish two verified `v1.2.0` portable WebDemo ZIPs containing the latest website, and present the repository with an evidence-bounded open-source-style README and explicit MIT/third-party license boundary.

**Architecture:** Keep the current model, WebDemo, results, and evidence files unchanged while adding a deterministic Python release-packaging unit at repository level. Build platform-specific archives from a strict allowlist, test their contents and ZIP metadata, then publish only assets generated from the verified `main` release commit. The README changes presentation and navigation while retaining the existing quantitative and methodological body.

**Tech Stack:** Python 3.12 standard library (`zipfile`, `hashlib`, `pathlib`), `unittest`, PowerShell 7, Git/GitHub CLI, React 19, Vite 8, Vitest 4, ONNX Runtime Web 1.29.

- [ ] **Step 3: Implement the minimal deterministic builder**

Implement:

```python
@dataclass(frozen=True)
class BuiltArchive:
    platform: str
    path: Path
    bytes: int
    sha256: str

def build_release_archives(
    repository_root: Path,
    output_dir: Path,
    version: str,
    source_date_epoch: int | None = None,
) -> tuple[BuiltArchive, BuiltArchive]:
    ...
```

The builder must validate semantic version `1.2.0`, use strict common/platform allowlists, recursively include the complete committed `web_demo/dist/`, reject symlinks and unsafe/colliding names, read source bytes without transformation except generated root launchers, and write deterministic ZIP entries sorted by archive name. Use the provided epoch or the current Git commit timestamp for every ZIP entry, clamp to the ZIP 1980 minimum, set UTF-8 and Unix creator metadata, use `0o755` only for directories and macOS shell/command launchers, and use `ZIP_DEFLATED` with `compresslevel=9`.

Generate the two root launchers with exact relative delegation:

```bat
@echo off
call "%~dp0web_demo\start-demo.bat" %*
exit /b %ERRORLEVEL%
```

```sh
#!/bin/sh
SCRIPT_DIR=$(CDPATH= cd -- "$(dirname -- "$0")" && pwd) || exit 1
exec "$SCRIPT_DIR/web_demo/start-demo.command" "$@"
```

The CLI accepts `--repository-root`, `--output-dir`, and `--version`, prints one tab-separated line per asset containing filename, bytes, and lowercase SHA-256, and exits nonzero on missing or unsafe inputs.
